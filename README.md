# FIT PRO

Plateforme fitness responsive en cours de construction. Le dépôt étant vide au démarrage, cette première étape initialise le projet et sa documentation. Les fonctionnalités déjà demandées restent au cahier des charges ; aucune intégration externe n'est déclarée opérationnelle sans configuration et tests.

## État initial

- Dépôt initialisé pour une application web Next.js + React + TypeScript.
- Architecture destinée à accueillir une API et PostgreSQL.
- Les fournisseurs OAuth, paiements, notifications et services externes nécessitent des identifiants et une configuration propres aux environnements.

Voir le guide de démarrage et l'état des intégrations dans la documentation du projet à mesure qu'ils sont ajoutés.
